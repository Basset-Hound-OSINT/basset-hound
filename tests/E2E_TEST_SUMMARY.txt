TROUBLESHOOTING GUIDE
================================================================================

ISSUE: Tests timeout (> 1 hour)
FIX: Check service startup logs
     docker compose logs --tail 30 basset_api

ISSUE: "Cannot connect to http://localhost:8000"
FIX: Verify API is running
     curl http://localhost:8000/health
     docker compose up -d

ISSUE: "All tests skipped"
FIX: Check endpoint configuration
     Review endpoint patterns in test file
     Verify API URL: echo $API_URL

ISSUE: Performance threshold failures
FIX: Check system resources
     docker stats
     Run test in isolation
     Adjust threshold if baseline changes

ISSUE: Database connection errors
FIX: Verify Neo4j connectivity
     curl http://localhost:7474
     docker compose down -v && docker compose up -d
     Wait 60 seconds for startup
